Privacy Policy

Last updated: 31 October 2026

This policy covers shorts-uploader, a private tool used only by the owner of the YouTube channel Kinetic Toon to upload their own videos.

YouTube API Services

shorts-uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Your use of YouTube data is also governed by the Google Privacy Policy (http://www.google.com/policies/privacy).

What data is accessed

With the user's permission (Google OAuth scopes youtube.upload and youtube.readonly), the tool:

  • uploads video files, titles, descriptions and tags that the user created, to the user's own channel;
  • reads the name of the signed-in channel, only to confirm which channel is connected.

It does not access viewers' data, comments, analytics, subscribers, playlists, or any other channel.

How data is used, stored and shared

  • The Google sign-in token (OAuth refresh token) is stored only in a local file on the user's own computer. It is used only to upload the user's videos.
  • A local log on the same computer keeps the IDs, titles and publish times of uploaded videos, to avoid duplicate uploads.
  • No data is sent to any server other than Google's. No data is sold, shared with third parties, or used for advertising.
  • The tool uses no cookies and no tracking. This website uses no cookies or analytics.

Revoking access and deleting data

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • Deleting the local token file removes all stored access immediately. The local upload log can be deleted at any time.
  • Stored YouTube data in the local log is refreshed or deleted within 30 days. To request deletion or ask a question, contact toonkinetic@gmail.com; requests are handled within 7 days.

Changes

Any change to this policy will be posted on this page with a new date.
