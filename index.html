shorts-uploader

shorts-uploader is a private tool used only by the owner of the Kinetic Toon channel. It runs on the owner's own computer and uses the YouTube Data API (YouTube API Services) to upload the owner's own finished videos to the owner's own channel and schedule their publish time.

It has no other users, is not offered to the public, and does not access any other channel or anyone else's data.
